# 正则表达式

## 是什么：

正则表达式（Regular Expression，简称 regex）是一种用于字符串匹配的模式规则。我们在规定好模式规则以后可以去查询符合规则的字符串，或者是查看特定的字符串是否满足模式规则。

## 为什么：

### （1）为什么要使用正则表达式？

现实中有很多需要我们对字符串进行匹配的场景，比如检查邮箱格式、查看用户输入的用户名是否满足要求、查看用户输入的电话号码是否满足要求等，这些场景如果用正则表达式进行书写就特别简单且方便。

## 怎么办：

### （1）如何使用正则表达式？

正则表达式主要有两个用途：给定格式查看一个字符串是否满足该格式（返回true或false），给定格式在一个大字符串中查询满足条件的子串(返回满足条件的子串)，接下来分别介绍这两种用法。

1. 用字符串`String regex`规定好正则表达式的构造然后让另一个字符串S通过`String.matches(String regex)`方法判断字符串S是否满足该正则表达式

   ```java
   //public boolean matches(String regex):判断是否与正则表达式匹配，匹配返回true
   System.out.println("a".matches("[abc]")); // true
   System.out.println("z".matches("[abc]")); // false
   ```

2. 给定格式，然后通过正则表达式Pattern对象和文本匹配器Matcher对象去一个大字符串中查询满足条件的子串

   ```java
    public static void main(String[] args) {
        /* 有如下文本，请按照要求爬取数据。
           Java自从95年问世以来，经历了很多版本，目前企业中用的最多的是Java8和Java11，
           因为这两个是长期支持版本，下一个长期支持版本是Java17，相信在未来不久Java17也会逐渐登上历史舞台
           要求:找出里面所有的JavaXX
        */
   
        String str = "Java自从95年问世以来，经历了很多版本，目前企业中用的最多的是Java8和Java11，" +
            "因为这两个是长期支持版本，下一个长期支持版本是Java17，相信在未来不久Java17也会逐渐登上历史舞台";
   
        //1.获取正则表达式的对象
        Pattern p = Pattern.compile("Java\\d{0,2}");
        //2.获取文本匹配器的对象
        //拿着m去读取str，找符合p规则的子串
        Matcher m = p.matcher(str);
   
        //3.利用循环获取
        /**
        	根据正则表达式以及文本对象，这里会匹配这样几个子串：
        	Java
           Java8
           Java11
           Java17
           Java17
        */
        while (m.find()) {
            String s = m.group();
            System.out.println(s);
        }
        
    }
   ```

   



## 1.1 正则表达式的概念及演示

- 在Java中，我们经常需要验证一些字符串，例如：年龄必须是2位的数字、用户名必须是8位长度而且只能包含大小写字母、数字等。正则表达式就是用来验证各种字符串的规则。它内部描述了一些规则，我们可以验证用户输入的字符串是否匹配这个规则。
- 先看一个不使用正则表达式验证的例子：下面的程序让用户输入一个QQ号码，我们要验证：
  - QQ号码必须是6--20位长度
  - 而且必须全部是数字
  - 而且首位不能为0

```java
package com.itheima.a08regexdemo;

public class RegexDemo1 {
    public static void main(String[] args) {
        /* 假如现在要求校验一个qq号码是否正确。
            规则:6位及20位之内，0不能在开头，必须全部是数字。
            先使用目前所学知识完成校验需求然后体验一下正则表达式检验。
        */

        String qq ="1234567890";
        System.out.println(checkQQ(qq));

        System.out.println(qq.matches("[1-9]\\d{5,19}"));

    }

    public static boolean checkQQ(String qq) {
        //规则:6位及20位之内，0不能在开头，必须全部是数字 。
        //核心思想:
        //先把异常数据进行过滤
        //下面的就是满足要求的数据了。
        int len = qq.length();
        if (len < 6 || len > 20) {
            return false;
        }
        //0不能在开头
        if (qq.startsWith("0")) {
            return false;
        }
        //必须全部是数字
        for (int i = 0; i < qq.length(); i++) {
            char c = qq.charAt(i);
            if (c < '0' | c > '9') {
                return false;
            }
        }
        return true;
    }
}
```

## 1.2 用正则表达式进行单个字符的匹配

在正则表达式中单个字符通常用一个方括号 `[]` 来表示，内部的字符列举出可以匹配的字符。

- 语法示例：

1. \[abc\]：代表a或者b，或者c字符中的一个。
2. \[^abc\]：代表除a,b,c以外的任何字符。
3. [a-z]：代表a-z的所有小写字符中的一个。
4. [A-Z]：代表A-Z的所有大写字符中的一个。
5. [0-9]：代表0-9之间的某一个数字字符。
6. [a-zA-Z0-9]：代表a-z或者A-Z或者0-9之间的任意一个字符。
7. [a-dm-p]：a 到 d 或 m 到 p之间的任意一个字符。 

- 代码示例：

```java
package com.itheima.a08regexdemo;

public class RegexDemo2 {
    public static void main(String[] args) {
        //public boolean matches(String regex):判断是否与正则表达式匹配，匹配返回true
        // 只能是a b c
        System.out.println("-----------1-------------");
        System.out.println("a".matches("[abc]")); // true
        System.out.println("z".matches("[abc]")); // false

        // 不能出现a b c
        System.out.println("-----------2-------------");
        System.out.println("a".matches("[^abc]")); // false
        System.out.println("z".matches("[^abc]")); // true
        System.out.println("zz".matches("[^abc]")); //false
        System.out.println("zz".matches("[^abc][^abc]")); //true

        // a到zA到Z(包括头尾的范围)
        System.out.println("-----------3-------------");
        System.out.println("a".matches("[a-zA-z]")); // true
        System.out.println("z".matches("[a-zA-z]")); // true
        System.out.println("aa".matches("[a-zA-z]"));//false
        System.out.println("zz".matches("[a-zA-Z]")); //false
        System.out.println("zz".matches("[a-zA-Z][a-zA-Z]")); //true
        System.out.println("0".matches("[a-zA-Z]"));//false
        System.out.println("0".matches("[a-zA-Z0-9]"));//true


        // [a-d][m-p] a到d，或m到p
        System.out.println("-----------4-------------");
        System.out.println("a".matches("[a-d][m-p]"));//true
        System.out.println("d".matches("[a-d][m-p]")); //true
        System.out.println("m".matches("[a-d][m-p]")); //true
        System.out.println("p".matches("[a-d][m-p]")); //true
        System.out.println("e".matches("[a-d][m-p]")); //false
        System.out.println("0".matches("[a-d][m-p]")); //false

        // [a-z&&[def]] a-z和def的交集。为:d，e，f
        System.out.println("----------5------------");
        System.out.println("a".matches("[a-z&[def]]")); //false
        System.out.println("d".matches("[a-z&&[def]]")); //true
        System.out.println("0".matches("[a-z&&[def]]")); //false

        // [a-z&&[^bc]] a-z和非bc的交集。(等同于[ad-z])
        System.out.println("-----------6------------_");
        System.out.println("a".matches("[a-z&&[^bc]]"));//true
        System.out.println("b".matches("[a-z&&[^bc]]")); //false
        System.out.println("0".matches("[a-z&&[^bc]]")); //false

        // [a-z&&[^m-p]] a到z和除了m到p的交集。(等同于[a-1q-z])
        System.out.println("-----------7-------------");
        System.out.println("a".matches("[a-z&&[^m-p]]")); //true
        System.out.println("m".matches("[a-z&&[^m-p]]")); //false
        System.out.println("0".matches("[a-z&&[^m-p]]")); //false

    }
}

```

## 1.4 在正则表达式使用预定义字符进行匹配

- 预定义字符示例：
  1. "." ： 匹配任何单个字符。
  2. "\d"：匹配任何单个数字字符（即[0-9]）。
  3. "\D"：匹配任何单个非数字字符（即`[^0-9]`）。
  4. "\s"： 匹配任何单个空白字符，如空格(` `，一个常见的空白字符)、制表符(`\t`，水平制表符用于在文本中插入一定的水平间距通常用于排版或格式化)、换行符(`\n`，换行字符用于表示行的结束)、回车符(`\r`，回车字符表示将光标返回到行的开头通常与换行符一起使用（`\r\n`）)等。
  5. "\S"： 匹配任何单个非空白字符（即`[^\s]`），只要不是空白字符就能匹配，随便它是英文字符还是数字字符等。
  6. "\w"：匹配任何单个单词字符，即字母、数字和下划线（即`[a-zA-Z_0-9]`）。
  7. "\W"：匹配任何单个非单词字符，即除字母、数字和下划线以外的字符（即`[^\w]`），注意中文字符不在字母、数字、下划线范围内。
- 代码示例：

```java
public class Demo {
	public static void main(String[] args) {
        //.表示任意一个字符
        System.out.println("你".matches("..")); //false，因为这里得匹配两个任意字符
        System.out.println("你".matches(".")); //true
        System.out.println("你a".matches(".."));//true

        /**
        如何理解这里匹配模式中的"\\d"？
        这里我们是想进行单个数字字符的匹配，所以得用到"\d"，但是因为"\"是特殊字符，所以得在它前面加上转移字符"\"，
        所以最后的匹配模式就成了"\\d"
        */
        System.out.println("a".matches("\\d")); // false
        System.out.println("3".matches("\\d")); // true
        System.out.println("333".matches("\\d")); // false，因为这里只能匹配一个数字字符

        //\\w只能是一位单词字符[a-zA-Z_0-9]
        /**
        如何理解这里匹配模式中的"\\w"？
        这里我们是想进行单个单词字符的匹配，所以得用到"\w"，但是因为"\"是特殊字符，所以得在它前面加上转移字符"\"，
        所以最后的匹配模式就成了"\\w"
        */
        System.out.println("z".matches("\\w")); // true
        System.out.println("2".matches("\\w")); // true
        System.out.println("21".matches("\\w")); // false
        System.out.println("你".matches("\\w"));//false

        // 非单词字符
        System.out.println("你".matches("\\W")); // true
        System.out.println("---------------------------------------------");
        // 以上正则匹配只能校验单个字符。
		
	}
}
```



## 1.5 在正则表达式中使用数量词进行同一个模式的多次重复匹配

上述我们已经见识过了单个字符的匹配比如验证一个字符是否是数字字符，但是有时候需要对同一个匹配模式进行多次重复比如验证用户输入的手机号码中每一位是否都是数字字符，这里就要用到数量词进行多次重复匹配。

- 语法示例：这里的X表示重复的匹配模式，比如：`"\\d{5,19}"`表示用于匹配是否是数字字符并且重复匹配5-19次（5-19次表示子字符串的长度），`"a{2,4}"` 表示匹配2到4个字母 `a`。
  1. X? : 对于X的匹配模式进行匹配0次或1次。
  2. X* : 对于X的匹配模式进行匹配0次到多次。
  3. X+ : 对于X的匹配模式进行匹配1次或多次。
  4. X{n} : 对于X的匹配模式进行匹配恰好n次。
  5. X{n,} : 对于X的匹配模式进行匹配至少n次。
  6. X{n,m}: 对于X的匹配模式进行匹配n到m次(n和m都是包含的)
- 代码示例：

```java
public class Demo {
	public static void main(String[] args) {
		 // 必须是数字 字母 下划线 至少 6位
        System.out.println("2442fsfsf".matches("\\w{6,}"));//true
        System.out.println("244f".matches("\\w{6,}"));//false，因为字符串的长度小于6位

        // 必须是数字和字符 必须是4位
        System.out.println("23dF".matches("[a-zA-Z0-9]{4}"));//true
        System.out.println("23 F".matches("[a-zA-Z0-9]{4}"));//false，空格不是规定的字符
        System.out.println("23dF".matches("[\\w&&[^_]]{4}"));//true
        
        //false，这里的匹配模式是只包括字母、数字（不包括下划线），并且字符长度为4位
        System.out.println("23_F".matches("[\\w&&[^_]]{4}"));
	}
}

```

## 1.6 正则表达式练习1

需求：

​	请编写正则表达式验证用户输入的手机号码是否满足要求。

​	验证邮箱号码 3232323@qq.com zhangsan@itcast.cnn dlei0009@163.com dlei0009@pci.com.cn

代码示例：

```java
package com.itheima.a08regexdemo;

public class RegexDemo4 {
    public static void main(String[] args) {
        /*
            需求
            请编写正则表达式验证用户输入的手机号码是否满足要求。请编写正则表达式验证用户输入的邮箱号是否满足要求。请编写正则表达式验证用户输入的电话号码是否满足要求。
            验证手机号码 13112345678 13712345667 13945679027 139456790271
            验证座机电话号码 020-2324242 02122442 027-42424 0712-3242434
            验证邮箱号码 3232323@qq.com zhangsan@itcast.cnn dlei0009@163.com dlei0009@pci.com.cn
        */

        //心得:
        //拿着一个正确的数据，从左到右依次去写。
        //13112345678
        //分成三部分:
        //第一部分:1 表示手机号码只能以1开头
        //第二部分:[3-9] 表示手机号码第二位只能是3-9之间的
        //第三部分:\\d{9} 表示任意数字可以出现9次，也只能出现9次
        String regex1 = "1[3-9]\\d{9}";
        System.out.println("13112345678".matches(regex1));//true
        System.out.println("13712345667".matches(regex1));//true
        System.out.println("13945679027".matches(regex1));//true
        System.out.println("139456790271".matches(regex1));//false
        System.out.println("-----------------------------------");

        //座机电话号码
        /**
        //020-2324242 02122442 027-42424 0712-3242434
        //思路:在书写座机号正则的时候需要把正确的数据分为三部分
        一:区号
        	区号长度为3-4位
        	区号一定是以0为开头的
        二:连字符部分
        	用于连接区号和号码，连字符是可选的，可以有或者没有。例如：020-2324242 或 0202324242 都可以匹配成功。             三:号码 
        	号码的第一位也不能以0开头，从第二位开始可以是任意的数字，号码的总长度:5-10位
        	
        注意这里的连字符部分：-?：表示对 "-" 匹配0次或1次，也就是说无论有没有 "-" 这个连字符都可以。
        */
        String regex2 = "0\\d{2,3}-?[1-9]\\d{4,9}";
        System.out.println("020-2324242".matches(regex2));
        System.out.println("02122442".matches(regex2));
        System.out.println("027-42424".matches(regex2));
        System.out.println("0712-3242434".matches(regex2));

        //邮箱号码
        /**
        //3232323@qq.com zhangsan@itcast.cnn dlei0009@163.com dlei0009@pci.com.cn
        //思路:在书写邮箱号码正则的时候需要把正确的数据分为三部分
        第一部分:@的左边
        	任意的字母数字下划线，至少出现一次
        第二部分:@本身 
        	只能出现一次
        第三部分:@的右边
			@右边的第一个部分（即域名主干部分，比如qq、163、itcast）：
				任意的字母、数字（不包括下划线），总共出现2-6次
            @右边的第二个部分（即顶级域名部分，比如.com、.cn、或.com.cn等）：
            	顶级域名内部可以是大小写字母，长度为2-3位(比如.com或.cn)；
            	顶级域名本身可以重复1-2次（比如.com.cn）
            	
        如何理解顶级域名这里的\\.？
        	在正则表达式中，点.是一个特殊字符，它表示可以匹配任何字符（除了换行符）。如果你想匹配字面上
        	的点字符.，需要使用"\."作为一个整体来表示一个普通的点字符，又因为\本身表示特殊字符，所以
        	还需要在"\."前面补充另一个\来表示后续的"\."作为一个普通字符。
        	有点不太理解这里的意思，但是没关系，只要记住转义字符一般都是两个反斜杠"\\"在一起起作用的。
        如何理解顶级域名这里的(\\.[a-zA-Z]{2,3}){1,2}？
        	其中括号内的部分(\\.[a-zA-Z]{2,3})本身就表示一个顶级域名，而括号外围的{1,2}表示重复1-2次，
        	与上述的顶级域名本身重复1-2次匹配
        */ 
        String regex3 = "\\w+@[\\w&&[^_]]{2,6}(\\.[a-zA-Z]{2,3}){1,2}";
        System.out.println("3232323@qq.com".matches(regex3));
        System.out.println("zhangsan@itcast.cnn".matches(regex3));
        System.out.println("dlei0009@163.com".matches(regex3));
        System.out.println("dlei0009@pci.com.cn".matches(regex3));
```

## 1.12 贪婪爬取和非贪婪爬取

1. 贪婪匹配（Greedy Match）：在正则表达式中，`*`（0次或多次）和 `+`（1次或多次）是**贪婪的**。意思是：**尽可能多地匹配字符**，直到不能再继续。

2. 非贪婪匹配（Lazy Match）：在正则表达式中形式是在 `*` 或 `+` 后面加一个 `?`，如：`*?`、`+?`。意思是：**尽可能少地匹配字符**，即“遇到第一个符合条件的就停”。

示例文本:

```java
String s = "Java自从95年问世以来，abbbbbbbbbbbbaaaaaaaaaaaaaaaaaa...";
```

这段文本中有连续出现很多个 `b` 和 `a`，比如：

```nginx
abbbbbbbbbbbb
```

==贪婪匹配的正则表达式：==

```java
String regex = "ab+";
```

这是一个**贪婪匹配**，含义是：

- `a`：匹配一个 `a`
- `b+`：匹配**1个或多个**连续的 `b`，并且是**尽可能多**

匹配结果：

在这段字符串中：

```nginx
abbbbbbbbbbbb
```

就会被一次性整体匹配出来为一整块 `"abbbbbbbbbbbb"`，因为 `b+` 是贪婪的，会尽可能多的匹配b字符。

==非贪婪匹配的正则表达式：==

```java
String regex = "ab+?";
```

- `+?` 表示 “匹配尽可能少的 b”
- 因此，当遇到字符串 `"abbbbbbbbbbbb"` 时：
  - `a` 会匹配一个 `a`
  - `b+?` 会**只匹配一个 b**（满足“至少一个”的最小要求）

匹配结果为：

```nginx
ab
```

代码示例：

```java

            贪婪爬取:在爬取数据的时候尽可能的多获取数据
            非贪婪爬取:在爬取数据的时候尽可能的少获取数据

            贪婪爬取:abbbbbbbbbbbb

        String s = "Java自从95年问世以来，abbbbbbbbbbbbaaaaaaaaaaaaaaaaaa" +
```

## 1.15 正则表达式-分组和反向引用

### notes：什么是“分组”和“反向引用”？

- 分组：`()`

  - 在正则表达式中，`()` 表示**分组**，可以提取子串、指定重复规则等。

  - 分组是**从左到右数左括号 `(` 的顺序来编号**的：第一个左括号对应 **第1组**，第二个是第2组，依此类推。

- 反向引用：`\1`、`\2`...

  - 表示引用**前面某一组**匹配到的内容。

  - 例如，`\1` 引用第1组，`\2` 引用第2组。

示例讲解：

需求 1：判断首尾是否是同一个字符

```java
String regex1 = "(.).+\\1";
```

分析：

- `(.)`：匹配任意一个字符，作为第1组。
- `.+`：匹配中间至少一个任意字符。
- `\\1`：**反向引用**第一组，即字符串的最后一位要等于最开始匹配的字符。

示例匹配结果：

| 字符串  | 解释                         | 匹配结果 |
| ------- | ---------------------------- | -------- |
| `a123a` | 首位都是 `a`                 | ✅ true   |
| `b456b` | 首尾都是 `b`                 | ✅ true   |
| `17891` | 首位 `1`，末位是 `1`         | ✅ true   |
| `&abc&` | 首尾都是 `&`                 | ✅ true   |
| `a123b` | 开头是 `a`，结尾是 `b`，不同 | ❌ false  |



需求 2：判断字符串“开头一段”和“结尾一段”是否完全一致（多个字符）

```java
String regex2 = "(.+).+\\1";
```

分析：

- `(.+)`：第1组，匹配1个或多个字符（比如 `abc`）
- `.+`：匹配中间任意内容
- `\\1`：匹配“与第1组一致”的结尾

示例匹配结果：

| 字符串      | 匹配的首尾     | 匹配结果 |
| ----------- | -------------- | -------- |
| `abc123abc` | `abc` 和 `abc` | ✅ true   |
| `b456b`     | `b` 和 `b`     | ✅ true   |
| `123789123` | `123` 和 `123` | ✅ true   |
| `&!@abc&!@` | `&!@` 和 `&!@` | ✅ true   |
| `abc123abd` | `abc` 和 `abd` | ❌ false  |



需求 3：判断字符串首尾部分是否一致，且首段字符**重复同一个字母**

```java
String regex3 = "((.)\\2*).+\\1";
```

分析：

- `(.)`：匹配1个字符（如 `a`），是第2组
- `\\2*`：这个字符重复0次或多次，例如 `aaa`、`bbb`、`111`
- 所以 `(.)\\2*` 就是若干个**同一个字符**
- 最外层再包一层 `((.)\\2*)` 是**第1组**，即整个“重复的字符片段”
- `.+`：匹配中间任意内容
- `\\1`：字符串结尾也必须重复这段相同的字符片段

示例匹配结果：

| 字符串      | 说明                                   | 匹配结果 |
| ----------- | -------------------------------------- | -------- |
| `aaa123aaa` | 开头 `aaa`，结尾 `aaa`，字符一致       | ✅ true   |
| `bbb456bbb` | 开头 `bbb`，结尾 `bbb`，字符一致       | ✅ true   |
| `111789111` | 开头 `111`，结尾 `111`                 | ✅ true   |
| `&&abc&&`   | 开头 `&&`，结尾 `&&`                   | ✅ true   |
| `aaa123aab` | 开头 `aaa`，结尾 `aab`（后面字符变了） | ❌ false  |

细节：如何识别组号？

只看左括号，不看右括号，按照左括号的顺序，从左往右，依次为第一组，第二组，第三组等等

```java
//需求1:判断一个字符串的开始字符和结束字符是否一致?只考虑一个字符
//举例: a123a b456b 17891 &abc& a123b(false)
// 反向引用:表示把第X组的内容再出来用一次
String regex1 = "(.).+\\1";
System.out.println("a123a".matches(regex1));
System.out.println("b456b".matches(regex1));
System.out.println("17891".matches(regex1));
System.out.println("&abc&".matches(regex1));
System.out.println("a123b".matches(regex1));
System.out.println("--------------------------");


//需求2:判断一个字符串的开始部分和结束部分是否一致?可以有多个字符
//举例: abc123abc b456b 123789123 &!@abc&!@ abc123abd(false)
String regex2 = "(.+).+\\1";
System.out.println("abc123abc".matches(regex2));
System.out.println("b456b".matches(regex2));
System.out.println("123789123".matches(regex2));
System.out.println("&!@abc&!@".matches(regex2));
System.out.println("abc123abd".matches(regex2));
System.out.println("---------------------");

//需求3:判断一个字符串的开始部分和结束部分是否一致?开始部分内部每个字符也需要一致
//举例: aaa123aaa bbb456bbb 111789111 &&abc&&
//(.):把首字母看做一组
// \\2:把首字母拿出来再次使用
// *:作用于\\2,表示后面重复的内容出现0次或多次
String regex3 = "((.)\\2*).+\\1";
System.out.println("aaa123aaa".matches(regex3));
System.out.println("bbb456bbb".matches(regex3));
System.out.println("111789111".matches(regex3));
System.out.println("&&abc&&".matches(regex3));
System.out.println("aaa123aab".matches(regex3));
```

## 1.16 正则表达式中的分组练习

需求:

​    将字符串：我要学学编编编编程程程程程程。

​    替换为：我要学编程

```java
String str = "我要学学编编编编程程程程程程";

//需求:把重复的内容替换为单个的
//学学                学
//编编编编            编
//程程程程程程        程
//  (.)表示把重复内容的第一个字符看做一组
//  \\1表示第一字符再次出现
//  + 至少一次
//  $1 表示把正则表达式中第一组的内容，再拿出来用
String result = str.replaceAll("(.)\\1+", "$1");
System.out.println(result);
```

正则表达式解析：

| 部分      | 含义                                              |
| --------- | ------------------------------------------------- |
| `(.)`     | 匹配任意一个字符，并把它作为**第一组**（group 1） |
| `\\1+`    | 表示**第一组匹配的字符**又重复出现**一次或多次**  |
| `(.)\\1+` | 所以整体就表示**两个或多个相同字符连在一起**      |

示例匹配：

| 匹配文本       | 匹配结果           |
| -------------- | ------------------ |
| `学学`         | `(学)(学)`         |
| `编编编编`     | `(编)(编编编)`     |
| `程程程程程程` | `(程)(程程程程程)` |

 `"$1"` 是什么？

- `"$1"` 是用来替换的字符串，表示“**使用第一组匹配的内容**”来替换整个匹配到的重复部分。

所以：

- `"学学"` 替换为 `"学"`
- `"编编编编"` 替换为 `"编"`
- `"程程程程程程"` 替换为 `"程"`

## 1.18 非捕获分组

非捕获分组：分组之后不需要再用本组数据，仅仅是把数据括起来。

### 是什么：

- 普通分组 `(...)`：会**占用组号**，可以通过 `\\1`、`\\2` 进行 **反向引用**。例如：

```java
(ab)\\1     // 匹配 ab + ab
```

- 非捕获分组 `(?:...)这种最常见`、`(?=...)`、`(?!...)`：只用于**结构化括号或逻辑判断**，但**不会占用组号**，所以 **不能用反向引用 `\\1` 来引用它**，否则报错或行为不符合预期。

```java
//身份证号码的简易正则表达式
//当对身份证号的最后一位采用非捕获分组后，不能用反向引用来引用该分组。
//特点:不占用组号
/**
    这里报错的原因：采用非捕获分组后又通过反向引用来引用它
    String regex1 ="[1-9]\\d{16}(?:\\d|x|x)\\1";
*/

String regex2 ="[1-9]\\d{16}(\\d Xx)\\1";
System.out.println("41080119930228457x".matches(regex2));
```
