# 1. 反射

## 1.1 反射的概述：

​	**专业的解释（了解一下）：**

​       是在运行状态中，对于任意一个类，都能够知道这个类的所有属性和方法；

​       对于任意一个对象，都能够调用它的任意属性和方法；

​       这种动态获取信息以及动态调用对象方法的功能称为Java语言的反射机制。

​	**通俗的理解：（掌握）**

* 利用**反射**创建的对象**可以无视修饰符**调用类里面的内容

* 可以跟**配置文件结合起来使用**，把要创建的对象信息和方法写在配置文件中。

  读取到什么类，就创建什么类的对象

  读取到什么方法，就调用什么方法

  此时当需求变更的时候不需要修改代码，只要修改配置文件即可。

## 1.2 学习反射到底学什么？

反射都是从class字节码文件中获取内容。

* 如何获取class字节码文件的对象
* 利用反射如何获取构造器（创建对象）
* 利用反射如何获取属性（赋值，获取值）
* 利用反射如何获取方法（运行）

### notes：`Class`与`class`的区别

`Class`：字节码文件对象的类，一般用在反射中，通过反射获取字节码文件对象就要用到`Class`

`class`：java语言的关键字，泛指一般的类，比如定义一个Student类，就是class Student{...}

## 1.3 获取字节码文件对象的三种方式

* 通过`Class.forName（“全类名”）`方法获取字节码文件对象**（最常用）**
* 通过`对象类.class`属性获取字节码文件对象
* 通过`对象.getClass()`方法获取字节码文件对象

代码示例：

```java
//1.Class这个类里面的静态方法forName
//Class.forName("类的全类名")： 全类名 = 包名 + 类名
Class clazz1 = Class.forName("com.itheima.reflectdemo.Student");
//源代码阶段获取 --- 先把Student加载到内存中，再获取字节码文件的对象
//clazz 就表示Student这个类的字节码文件对象。
//就是当Student.class这个文件加载到内存之后，产生的字节码文件对象


//2.通过class属性获取
//类名.class
Class clazz2 = Student.class;

//因为class文件在硬盘中是唯一的，所以，当这个文件加载到内存之后产生的对象也是唯一的
System.out.println(clazz1 == clazz2);//true


//3.通过Student对象获取字节码文件对象
Student s = new Student();
Class clazz3 = s.getClass();
System.out.println(clazz1 == clazz2);//true
System.out.println(clazz2 == clazz3);//true
```

## 1.4 字节码文件和字节码文件对象

java文件：就是我们自己编写的java代码。

字节码文件：就是java文件编译之后的class文件（是在硬盘上真实存在的，用眼睛能看到的）

字节码文件对象：当class文件加载到内存之后，虚拟机自动创建出来的对象。

​				这个对象里面至少包含了：构造器，属性，方法。

而我们的反射获取的是什么？字节码文件对象，这个对象在内存中是唯一的。

## 1.5 通过Class对象获取构造器

规则：

- `getConstructor(Class<?>... parameterTypes)`：获取指定参数的public权限的构造器（这是啥意思呢？一般构造器我们会给它传入参数，比如定义一个Student类里面有两个属性：`String name`，`int age`，后续可能会定义很多种的构造器，空参构造器、只有一个参数的构造器、全参构造器，现在我们通过指定参数类型为String类型、int类型的参数进而确定调用的是全参的构造器）
- `getDeclaredConstructor(Class<?>... parameterTypes)`：获取指定参数的public、private权限的构造器
- `getConstructors()`：获取所有的public构造器
- `getDeclaredConstructors()`：获取所有的public、private构造器

==notes：如果获取到的是private权限的构造器，必须临时修改访问权限后才能使用==	

| 方法名                                                       | 说明                              |
| ------------------------------------------------------------ | --------------------------------- |
| Constructor<?>[] getConstructors()                           | 获得所有的构造（只能public修饰）  |
| Constructor<?>[] getDeclaredConstructors()                   | 获得所有的构造（包含private修饰） |
| Constructor<T> getConstructor(Class<?>... parameterTypes)    | 获取指定构造（只能public修饰）    |
| Constructor<T> getDeclaredConstructor(Class<?>... parameterTypes) | 获取指定构造（包含private修饰）   |

代码示例：

```java
public class ReflectDemo2 {
    public static void main(String[] args) throws ClassNotFoundException, NoSuchMethodException {
        //1.获得整体（class字节码文件对象）
        Class clazz = Class.forName("com.itheima.reflectdemo.Student");


        //2.获取构造方法对象
        //获取所有构造方法（public）
        Constructor[] constructors1 = clazz.getConstructors();
        for (Constructor constructor : constructors1) {
            System.out.println(constructor);
        }

        System.out.println("=======================");

        //获取所有构造（带私有的）
        Constructor[] constructors2 = clazz.getDeclaredConstructors();

        for (Constructor constructor : constructors2) {
            System.out.println(constructor);
        }
        System.out.println("=======================");

        //获取指定的空参构造
        Constructor con1 = clazz.getConstructor();
        System.out.println(con1);

        Constructor con2 = clazz.getConstructor(String.class,int.class);
        System.out.println(con2);

        System.out.println("=======================");
        //获取指定的构造(所有构造都可以获取到，包括public包括private)
        Constructor con3 = clazz.getDeclaredConstructor();
        System.out.println(con3);
        //了解 System.out.println(con3 == con1);
        //每一次获取构造方法对象的时候，都会新new一个。

        Constructor con4 = clazz.getDeclaredConstructor(String.class);
        System.out.println(con4);
    }
}
```

## 1.7 通过Class对象获取属性

规则：

- `getField(String fieldName)`：根据属性名获取指定的public权限的属性（这是啥意思呢？比如说现在有一个Student类，其中有一个String类型的属性name，那么通过反射`Class.getField("name")`我们就可以获取到该属性）
- `getDeclaredField(String fieldName)`：根据属性名获取指定的public、private权限的属性
- `getFields()`：获取所有public权限的属性
- `getDeclaredFields()`：获取所有public、private权限的属性

==notes：如果获取到的是private权限的属性，必须临时修改访问权限后才能使用==	

方法名：

| 方法名                              | 说明                                         |
| ----------------------------------- | -------------------------------------------- |
| Field[] getFields()                 | 返回所有成员变量对象的数组（只能拿public的） |
| Field[] getDeclaredFields()         | 返回所有成员变量对象的数组，存在就能拿到     |
| Field getField(String name)         | 返回单个成员变量对象（只能拿public的）       |
| Field getDeclaredField(String name) | 返回单个成员变量对象，存在就能拿到           |

```java
public class ReflectDemo4 {
    public static void main(String[] args) throws ClassNotFoundException, NoSuchFieldException {
        //获取成员变量对象

        //1.获取class对象
        Class clazz = Class.forName("com.itheima.reflectdemo.Student");

        //2.获取成员变量的对象（Field对象)只能获取public修饰的
        Field[] fields1 = clazz.getFields();
        for (Field field : fields1) {
            System.out.println(field);
        }
        System.out.println("===============================");

        System.out.println(field4);

        这里最后输出的内容如下：权限 字段类型 全类名.属性名

        System.out.println(field5);
```

### notes：通过反射`Class.getField(String fieldName)`获取到属性到底是什么意思？

是获取到该属性的值嘛？其实不是，而是获取到该属性的所有内容，比如说现在有一个Student类，其中有一个String类型的属性name，那么通过反射`Class.getField("name")`我们就可以获取到该属性的所有内容：权限修饰符、字段类型、属性名。

```java
public class Student {
    public String name;
}

// 反射获取字段信息
Field field = Student.class.getField("name");

System.out.println(field.getName());         // 输出: name
System.out.println(field.getType());         // 输出: class java.lang.String
System.out.println(Modifier.toString(field.getModifiers())); // 输出: public
```

## 1.9 通过Class对象获取方法

规则：

- `getMethod(String name, Class<?>... parameterTypes)`：根据方法名和方法对应的参数类型获取指定类型的public权限的方法（这是啥意思呢？比如说现在有一个Student类，其中有一个方法需要传入String类型的参数：eat(String something)，那么通过反射`Class.getMethod("eat",String.class)`我们就可以获取到该方法）
- `getDeclaredMethod(String name, Class<?>... parameterTypes) ` ：根据方法名和方法对应的参数类型获取指定类型的public、private权限的方法
- `getMethods()`：获取所有public权限的方法
- `getDeclaredMethods()`：获取所有public、private权限的方法

==notes：如果获取到的是private权限的方法，必须临时修改访问权限后才能使用==		

| 方法名                                                       | 说明                                         |
| ------------------------------------------------------------ | -------------------------------------------- |
| Method[] getMethods()                                        | 返回所有成员方法对象的数组（只能拿public的） |
| Method[] getDeclaredMethods()                                | 返回所有成员方法对象的数组，存在就能拿到     |
| Method getMethod(String name, Class<?>... parameterTypes)    | 返回单个成员方法对象（只能拿public的）       |
| Method getDeclaredMethod(String name, Class<?>... parameterTypes) | 返回单个成员方法对象，存在就能拿到           |

代码示例：

```java
public class ReflectDemo6 {
    public static void main(String[] args) throws ClassNotFoundException, NoSuchMethodException {
        //1.获取class对象
        Class<?> clazz = Class.forName("com.itheima.reflectdemo.Student");


        //2.获取方法
        //getMethods可以获取父类中public修饰的方法
        Method[] methods1 = clazz.getMethods();
        for (Method method : methods1) {
            System.out.println(method);
        }
        System.out.println("===========================");
        
        //获取所有的方法（包含私有）
        //但是只能获取自己类中的方法
        Method[] methods2 = clazz.getDeclaredMethods();
        for (Method method : methods2) {
            System.out.println(method);
        }
        System.out.println("===========================");
     
        
        
        //获取指定的方法（空参）
        Method method3 = clazz.getDeclaredMethod("sleep");
        /**
        输出内容为：权限 返回类型 全类名.方法名(参数类型)
        private void org.example.Student2.sleep()
        */
        System.out.println(method3);

        Method method4 = clazz.getMethod("eat",String.class);
        /**
        输出内容为：权限 返回类型 全类名.方法名(参数类型)
        public java.lang.String org.example.Student2.eat(java.lang.String)
        */
        System.out.println(method4);

        //获取指定的私有方法
        Method method5 = clazz.getDeclaredMethod("playGame");
        /**
        输出内容为：权限 返回类型 全类名.方法名(参数类型)
        private void org.example.Student2.playGame()
        */
        System.out.println(method5);
    }
}
```

## 1.10 通过Class对象获取方法并运行



方法

 Object invoke(Object obj, Object... args) ：运行方法

参数一：用obj对象调用该方法

参数二：调用方法的传递的参数（如果没有就不写）

返回值：方法的返回值（如果没有就不写）

代码示例：

```java
package com.itheima.a02reflectdemo1;

import java.lang.reflect.InvocationTargetException;
import java.lang.reflect.Method;

public class ReflectDemo7 {
    public static void main(String[] args) throws ClassNotFoundException, NoSuchMethodException, InvocationTargetException, IllegalAccessException {
        //1.获取字节码文件对象
        Class clazz = Class.forName("com.itheima.a02reflectdemo1.Student");
		
        //2.获取一个对象（注意这里的对象是通过直接new的方式获取的，不是通过反射得到的构造器.newInstance()方式获取的）
        //需要用这个对象去调用方法
        Student s = new Student();
        
        //3.获取一个指定的方法
        //参数一：方法名
        //参数二：参数类型列表，如果没有可以不写
        Method eatMethod = clazz.getMethod("eat",String.class);
        
        //运行
        //参数一：表示方法的调用对象
        //参数二：方法在运行时需要的实际参数
        //注意点：如果方法有返回值，那么需要接收invoke的结果
        //如果方法没有返回值，则不需要接收
        String result = (String) eatMethod.invoke(s, "重庆小面");
        System.out.println(result);
        /**
        这里最后的输出结果：
        学生在吃重庆小面
		学生已经吃完了，非常happy
        */

    }
}
```

## 1.14 利用反射保存对象中的信息（重点）

我们知道对象是存在于内存中的，当发生宕机或程序结束等情况时，内存中的对象信息就会消失（除非你特意将它存入数据库等操作），对于一些很重要的对象信息我们是希望它能够永久保存的，为了实现这一点我们可以采用反射获取对象的所有属性信息然后通过输出流将它们输出到磁盘上

```java
public class MyReflectDemo {
    public static void main(String[] args) throws IllegalAccessException, IOException {
    /*
        对于任意一个对象，都可以把对象所有的字段名和值，保存到文件中去
    */
       Student s = new Student("小A",23,'女',167.5,"睡觉");
       Teacher t = new Teacher("播妞",10000);
       saveObject(s);
    }

    //把对象里面所有的成员变量名和值保存到本地文件中
    public static void saveObject(Object obj) throws IllegalAccessException, IOException {
        //1.获取字节码文件的对象
        Class clazz = obj.getClass();
        //2. 创建IO流
        BufferedWriter bw = new BufferedWriter(new FileWriter("myreflect\\a.txt"));
        //3. 获取所有的成员变量
        Field[] fields = clazz.getDeclaredFields();
        for (Field field : fields) {
            field.setAccessible(true);
            //获取成员变量的名字
            String name = field.getName();
            //获取成员变量的值
            Object value = field.get(obj);
            //写出数据
            bw.write(name + "=" + value);
            bw.newLine();
        }

        bw.close();

    }
}
```

# notes：代理

## 是什么：

可以简单理解为一个人代替另一个人去做某件事，这里代替去做事的人叫做代理类，被代替的人叫做被代理类

## 为什么：

### （1）为什么要使用代理？

可以简单理解为，原先的被代理类代码已经写死了不好修改，所以现在通过代理类去对原有的代码进行一些修改操作。

## 怎么办：

### （1）代理有哪些分类？

- 静态代理：提前写好所有代理类，代理类的代码在编译前就确定，每个被代理的类都需要一个对应的代理类，写起来繁琐但直观易懂。
- 动态代理：并非提前写好代理类而是在运行时才通过反射创建代理类，大大减少了重复代码，非常适合**面向接口编程**和AOP（如日志、权限校验等）。

### （2）如何使用代理？

#### ①如何使用静态代理？

```java
interface Painter {
    void paint();
}

class RealPainter implements Painter {
    public void paint() {
        System.out.println("画家正在画画...");
    }
}

class PainterProxy implements Painter {
    private RealPainter realPainter;

    public PainterProxy(RealPainter realPainter) {
        this.realPainter = realPainter;
    }

    public void paint() {
        System.out.println("代理：准备颜料...");
        realPainter.paint();
        System.out.println("代理：清理画室...");
    }
}
```

使用时：

```java
// 创建真实对象
RealPainter realPainter = new RealPainter();
// 创建代理对象，把真实对象交给代理
Painter proxy = new PainterProxy(realPainter);
// 通过代理调用 paint 方法
proxy.paint();
```



#### ②如何使用动态代理？（关于动态代理的详细介绍见下述）

```java
import java.lang.reflect.*;

interface Painter {
    void paint();
}

class RealPainter implements Painter {
    public void paint() {
        System.out.println("画家正在画画...");
    }
}

class ProxyFactory {
    public static Object createProxy(Object target) {
        return Proxy.newProxyInstance(
            target.getClass().getClassLoader(),
            target.getClass().getInterfaces(),
            (proxy, method, args) -> {
                System.out.println("代理：准备颜料...");
                Object result = method.invoke(target, args);
                System.out.println("代理：清理画室...");
                return result;
            }
        );
    }
}
```

使用时：


# 2. 动态代理（这里描述的都是jdk动态代理，基于接口实现的，至于CGLib动态代理暂时不介绍）

## 是什么：

是代理的一种，并非提前写好代理类而是在运行时才通过反射创建代理类，大大减少了重复代码，非常适合**面向接口编程**和AOP（如日志、权限校验等）。动态代理的==核心是**在运行时生成字节码**，动态创建实现指定接口的代理类（无需手动编写`.java`文件）==。==生成的代理类会重写接口方法，并在方法中调用`InvocationHandler.invoke()`实现逻辑控制==。

## 为什么：

### （1）为什么要使用动态代理？

无侵入式的给方法增强功能，比如现在有一个明星类，它里面定义了唱歌、跳舞的方法（里面全是唱歌、跳舞的逻辑），现在别人邀请明星去唱歌、跳舞，所以直接执行明星内部的唱歌、跳舞方法就行了嘛？当然不行，其中还牵扯到关于价钱的讨论等（唱一首歌多少钱），所以我们需要对原有的唱歌、跳舞方法进行增强，但是如果直接在原有的方法中进行修改就很不合适，所以选择动态代理。

## 怎么办：

### （1）动态代理三要素？

1. 代理类：真正干活的人
2. 被代理类
3. 通过代理类执行方法

notes：代理可以增强或者拦截的方法都在接口中，接口需要写在newProxyInstance的第二个参数里。

### （2）如何使用动态代理增强原有方法？

1. 创建接口

   ```java
   public interface Star {
       //我们可以把所有想要被代理的方法定义在接口当中
       //唱歌
       public abstract String sing(String name);
       //跳舞
       public abstract void dance();
   }
   ```

2. 创建被代理类

   ```java
   public class BigStar implements Star {

   ```

3. 创建代理类工厂，在运行时通过反射动态创建代理类

   ==其实代理类工厂的创建可有可无==，它的内部是通过反射创建代理类，现在==有了工厂的话我们可以将内部的实现细节封装起来，在业务代码中直接使用工厂类创建代理对象==，但是如果==没有代理类工厂的话在业务代码中我们自己通过反射创建代理类对象也是可以的==

   ```java
   /*
   * 代理类工厂的作用：通过反射创建一个代理类对象
   */
   public class ProxyUtil {
       
       /*
       * 方法的作用：给一个被代理的明星对象，通过反射创建一个代理对象
       *  形参：被代理的明星对象
       *  返回值：给明星创建的代理
       * 需求：
       *   外面的人想要大明星唱一首歌
       *   1. 获取代理的对象
       *      代理对象 = ProxyUtil.createProxy(大明星的对象);
       *   2. 再调用代理的唱歌方法
       *      代理对象.唱歌的方法("只因你太美");
       * */
       public static Star createProxy(BigStar bigStar){
          /* 
           通过 java.lang.reflect.Proxy类的newProxyInstance方法创建代理对象：
           public static Object newProxyInstance(ClassLoader loader, 
           									  Class<?>[] interfaces, 
           									  InvocationHandler h)
           参数一：代理类工厂的类加载器，表明用该类加载器去加载生成的代理类
           参数二：指定接口数组，这些接口表明了代理类要去做哪些事
           参数三：用来指定代理类做事的逻辑
           */
           Star star = (Star) Proxy.newProxyInstance(
                   ProxyUtil.class.getClassLoader(),//参数一：代理类工厂的类加载器，用该类加载器去加载生成的代理类
                   new Class[]{Star.class},//参数二：指定接口，这些接口表明了代理类要去做哪些事
                   //参数三：用来指定代理类做事的逻辑
                   new InvocationHandler() {
                       @Override
                       public Object invoke(Object proxy, Method method, Object[] args) throws Throwable {
                           /*
                           * 参数一：代理的对象
                           * 参数二：要运行的方法 sing
                           * 参数三：调用sing方法时，传递的实参
                           * */
                           if("sing".equals(method.getName())){
                               System.out.println("准备话筒，收钱");
                           }else if("dance".equals(method.getName())){
                               System.out.println("准备场地，收钱");
                           }
                           //去找大明星开始唱歌或者跳舞
                           //代码的表现形式：调用大明星里面唱歌或者跳舞的方法
                           return method.invoke(bigStar,args);
                       }
                   }
           );
           return star;
       }
   }
   ```

### （3）如何使用动态代理拦截原有方法？

动态代理除了可以增强原有方法外还可以拦截对原有方法的调用，比如：在这个故事中，经济人作为代理，如果别人让邀请大明星去唱歌，打篮球，经纪人就增强功能。但是如果别人让大明星去扫厕所，经纪人就要拦截，不会去调用大明星的方法。

其实它的原理很简单，在代理类对象中规定当执行某一个方法时让它不要执行该方法就表示被拦截了。

```java
/*
* 类的作用：
*       创建一个代理
* */
public class ProxyUtil {
    public static Star createProxy(BigStar bigStar){
        public static Object newProxyInstance(ClassLoader loader, Class<?>[] interfaces, InvocationHandler h)
        Star star = (Star) Proxy.newProxyInstance(
                ProxyUtil.class.getClassLoader(),
                new Class[]{Star.class},
                new InvocationHandler() {
                    @Override
                    public Object invoke(Object proxy, Method method, Object[] args) throws Throwable {
                        if("cleanWC".equals(method.getName())){
                            System.out.println("拦截，不调用大明星的方法");
                            return null;
                        }
                        //如果是其他方法，正常执行
                        return method.invoke(bigStar,args);
                    }
                }
        );
        return star;
    }
}
```

### （4）动态代理的练习：没有代理类工厂该咋办

现在我们通过动态代理实现：对ArrayList对象的add方法进行增强，对remove方法进行拦截，对其他方法不拦截也不增强

```java
public class MyProxyDemo1 {
    public static void main(String[] args) {
        //动态代理可以增强方法也可以拦截方法
        //1.创建被代理类
        ArrayList<String> list = new ArrayList<>();

        //2.创建代理对象
        /*
        参数一：代理类工厂的类加载器，负责将代理类对象记载到内存中，当前没有代理类工厂而是在业务代码中自己创建的
        	   代理类对象，所以就填当前业务类的类加载器。
        参数二：指定接口数组，这些接口表明了代理类要去做哪些事
        参数三：用来指定代理类做事的逻辑             
        */
        List proxyList = (List) Proxy.newProxyInstance(
                //参数一：代理类工厂的类加载器
                MyProxyDemo1.class.getClassLoader(),
                //参数二：指定接口数组，这些接口表明了代理类要去做哪些事
                new Class[]{List.class},
                //参数三：用来指定代理类做事的逻辑  
                new InvocationHandler() {
                    @Override
                    /*
                    invoke方法参数的意义
                    	参数一：表示代理对象，一般不用（了解）
                    	参数二：就是方法名，我们可以对方法名进行判断，是增强还是拦截
                    	参数三：就是下面第三步调用方法时，传递的参数。
                    举例1：
                    	list.add("阿玮好帅");
                    	此时参数二就是add这个方法名
                    	此时参数三 args[0] 就是 阿玮好帅
                    举例2：
                    	list.set(1, "aaa");
                    	此时参数二就是set这个方法名
                    	此时参数三  args[0]就是1  args[1]就是"aaa"
                    */
                    public Object invoke(Object proxy, Method method, Object[] args) throws Throwable {
                        //对add方法做一个增强，统计耗时时间
                        if (method.getName().equals("add")) {
                            long start = System.currentTimeMillis();
                            //调用集合的方法，真正的添加数据
                            method.invoke(list, args);
                            long end = System.currentTimeMillis();
                            System.out.println("耗时时间：" + (end - start));
                            //需要进行返回，返回值要跟真正增强或者拦截的方法保持一致
                            return true;
                        }else if(method.getName().equals("remove") && args[0] instanceof Integer){
                            System.out.println("拦截了按照索引删除的方法");
                            return null;
                        }else if(method.getName().equals("remove")){
                            System.out.println("拦截了按照对象删除的方法");
                            return false;
                        }else{
                            //如果当前调用的是其他方法,我们既不增强，也不拦截
                            method.invoke(list,args);
                            return null;
                        }
                    }
                }
        );

        //3.通过代理类对象执行方法
        /*
        如果执行者是原先的被代理对象list，就好比绕过了第二步的代码，直接添加元素
        如果执行者是代理对象，此时代理才能帮我们增强或者拦截

        通过代理对象每次执行方法的时候，都不会直接操作集合，而是先调用代理里面的invoke，
        在invoke方法中进行判断，可以增强或者拦截
        */
        proxyList.add("aaa");
        proxyList.add("bbb");
        proxyList.add("ccc");
        proxyList.add("ddd");

        proxyList.remove(0);
        proxyList.remove("aaa");


        //打印集合
        System.out.println(list);
    }
```
